## What's changed

Four World of Balance monsters off the story's path now have shields designed
for them: the Bug and the ChickenLip in the forests by Albrook, the Grenade on
the bomb isle, and the Intangir on Triangle Island. The Grenade explodes when a
Fight hits it without breaking it, so break it in one swing, or use Edgar's
tools and Sabin's blitzes, which it does not answer. The Intangir absorbs every
element, so a weapon that carries one heals it, but Locke's knife, Edgar's
tools, Sabin's blitzes and Setzer's cards and dice all break it. A broken
Intangir loses its turns, so it cannot answer your hits with Meteo or run away,
and with it broken you can finally bring it down.
