# Fixtures where a party member holding nothing is the STORY, not a bug.
#
# Format:  <fixture>\t<CHARACTER>\t<why, and which step arms them>
#
# The rule this waives is tools/audit_equipment.py: nobody walks the story
# bare-handed, because a wrong fixture reads exactly like a balance wall
# (solo LOCKE punched a 495-hp HeavyArmor for eight damage a swing for
# three runs before anyone read his equipment block).
#
# A waiver is only legitimate when the fixture captures the exact moment
# the game itself took the gear away and the very next step puts it back.
# "This step is hard" is never a reason.  Like the state-write list, this is
# a BURN-DOWN: a line that matches nothing fails the run, so a fixture that
# gets armed upstream cannot quietly keep its exemption.
#
# UMARO and GAU are not listed and never need to be: the game's own weapon
# test (ItemProp +$00 & $07 == $01) and equip mask (+$01, bit N = actor N)
# say each of them can hold exactly one weapon record in this ROM -- UMARO
# the Bone Club, GAU the $24 Imp Halberd, which no shop stocks -- so
# audit_equipment excludes them from the data rather than from a list.
# Their waiver lines were deleted on 2026-08-13 when the audit started
# reading the type byte instead of assuming records $00..$5F were weapons.
