# Uninitialised reads, understood, for the power-on fill
# (OT6_POWERON_FILL, lib/poweron_fill.lua) and the read-before-write
# instrument (OT6_RBW, tools/rbw_report.py).  docs/TOOLING.md "Uninitialised
# memory".
#
#   fill <region> <lo>[-<hi>] <reason>
#       the fill leaves these offsets zero, so a read already understood
#       does not move the play and hide what comes after it.
#   unread <region> <lo>[-<hi>] <reason>
#       rbw_report.py counts any instruction's reads of these offsets
#       without listing them (the fill still fills them).
#   read <file>:<line> <region> <reason>
#       rbw_report.py counts this instruction's reads without listing them.
#
# Two sections.  TO FIX: reads that move the play, or OT6 reads that should
# be cleared at their init; each names the fix, and goes when the ROM fixes
# it.  NO PLAY EFFECT: reads shown not to move the play (the evidence is
# each line's; the blanket evidence is the power-on-leg wave, which fills
# everything not waived as `fill` and plays the same), kept so the
# detector lists only what is new.

# ---------------------------------------------------------------- TO FIX
# (none: v0.46 zeroes every read this section listed -- Ot6NewGameClear and
# Ot6PowerOnClear, InitBP, InitBattleGfx, InitWaterGfx; #543 removed
# OT6_GREYLIVE)
