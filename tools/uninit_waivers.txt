# Uninitialised reads proven benign, for the power-on fill
# (OT6_POWERON_FILL, lib/poweron_fill.lua) and the read-before-write
# instrument (OT6_RBW, tools/rbw_report.py).  docs/TOOLING.md "Uninitialised
# memory".
#
#   fill <region> <lo>[-<hi>] <reason>
#       the fill leaves these offsets zero, so a read already understood
#       does not move the play and hide what comes after it.  Each one names
#       the instruction, what the value changes, and the evidence.
#   read <file>:<line> <ram> <reason>
#       tools/rbw_report.py counts this instruction's reads of unwritten
#       bytes without listing them.
#
# A waiver is a finding, not a fix: each says why it is harmless, or why it
# is left for the ROM's owner (the proposed fix is in the reason).

Fix: zero it in Ot6NewGameClear. build/attempts/wt/v046-fills/regions/gen_whelk_poweron_ones_wram_1F6E-1F6F.log
